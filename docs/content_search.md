# ドキュメントのスコープ
本ドキュメントは以下をスコープとする。

- 本アプリケーションの検索機能において利用可能な条件

# 検索機能の条件
## 検索条件の概要
検索条件（Condition）は、0個以上の項（Term）のAND条件として構成される。
0個の場合には全件が対象となる。

項は対象（Object）と述語（Predicate）から成る。

以上をまとめると、検索条件は以下のように表現できる。
なお、以下の表現は実際の表現形式を規定せず、あくまでも概念的な表現である。

```
Condition := | Term ( AND Term )*

Term := Object Predicate
```

## 対象（Object）
対象（Object）は、検索対象となるコンテンツの属性を表す。

対象は、

- コンテンツファイルのファイルフォーマット
- [content_files.md](./content_files.md)で記載されたタグ名

の2種類がある。

## 述語（Predicate）
### 対象がファイルフォーマットの場合の述語
対象がファイルフォーマットの場合、述語は以下のいずれかである。

- 一致：コンテンツのファイルフォーマットが、指定された1つ以上のファイルフォーマットのいずれかと一致するかどうか

### 対象がタグ名の場合の述語
対象がタグ名の場合、述語は以下のいずれかである。

- 存在：コンテンツにタグ名と一致するタグが存在するかどうか
- 一致：コンテンツのタグの値が、指定された1つ以上の値のいずれかと一致するかどうか
    - 配列型のタグの場合には、いずれかと一致する要素が存在するかどうか
    - キーのみのタグの場合には不一致
    - タグが存在しなければ不一致

## タグに関する検索条件の特記事項
タグに関する検索条件においては、上記に加え以下の特記事項がある。

- タグ名や値の指定は、[content_files.md](./content_files.md)で定義されたフォーマットに則る場合のみ有効となる
- タグの値の一致は、指定中で型を明示しその型として解釈した値によって比較する。この際、型が異なる場合には不一致となる。
