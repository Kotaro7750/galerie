# ドキュメントのスコープ
本ドキュメントでは以下をスコープとする。

* このリポジトリにおけるアーティファクトの一覧
* それぞれのアーティファクトで使用するディレクトリの配置

# アーティファクトの一覧
このリポジトリにおいては、以下のアーティファクトを作成する。
なお、ディレクトリに関しては相対パス指定の場合特に指定がなければリポジトリルートを基準とする。

- フロントエンドSPA
  - ディレクトリ: `frontend` 
  - ドキュメント階層: `docs/frontend`配下
- バックエンドAPIサーバー
  - ディレクトリ: `backend`
  - ドキュメント階層: `docs/backend`配下
