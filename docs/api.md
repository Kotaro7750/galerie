# 本システムにおけるAPIの設計思想
本システムにおけるAPIは契約ファーストとし、契約としてのAPIドキュメントを正本とし実装が準拠するということを原則とする。

この際、APIドキュメントからコードを自動生成することを推奨する。

# 契約ドキュメントの配置
フロントエンドSPAとバックエンドAPIサーバーの間の契約ドキュメントは、`contracts`ディレクトリに配置することとし、バージョン管理に含めることとする。
