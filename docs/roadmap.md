# ロードマップ
## 初回リリース
初回リリースにおいては、以下の機能を実装した最低限のバージョンとする。

* 対応コンテンツファイルは画像のみとする。
* コンテンツストレージ実装は、ファイルシステム上の正規コンテンツ及びXMPサイドカーを読み取り専用で扱うものとする。
* ユーザーは検索機能を伴わないサムネイル一覧画面を閲覧することができる。
* サムネイル一覧画面ではスクロールしていくと自動的に次のサムネイル群が読み込まれていく。
* ユーザーはサムネイルをクリックすることで、対応するコンテンツファイルを閲覧することができる。
