# ドキュメントのスコープ
本ドキュメントは以下をスコープとする。

- フロントエンドSPAにおける個々のページの設計
- フロントエンドSPAにおけるURL設計

# 認証について
ページ設計において明記されていない限り、認証が必要であり未認証の場合にはそのページではなくログイン操作を代わりに表示する。

ただし、認証を無効にしたビルドの場合には認証の確認を行わず未認証でもページを表示する。

# ページ設計
## ページの一覧

- トップページ
- コンテンツ一覧ページ
- コンテンツページ
- コンテンツ登録ページ

## トップページ設計
トップページは認証が不要であり、最初にアクセスした際に表示されるページである。

## コンテンツ一覧ページ
コンテンツ一覧ページはバックエンドAPIサーバーから取得したコンテンツ情報を元に、サムネイル一覧を表示するページである。

このページはページングを用いず、無限スクロールによってコンテンツ一覧を表示する。

## コンテンツページ
コンテンツページはコンテンツ一覧ページで特定のコンテンツを選んだ際に表示されるページである。

## コンテンツ登録ページ
コンテンツ登録ページはコンテンツを新たに登録するページである。
